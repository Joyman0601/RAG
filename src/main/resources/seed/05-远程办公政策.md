# 远程办公政策

## 远程办公资格

以下情况允许申请远程办公：
- **常态化远程**：需部门总监审批，一般限于研发、设计、写作、数据分析等无需现场协作的岗位
- **临时远程**：因家庭事务、身体不适、恶劣天气等，员工直接向直属主管报备即可，全年累计不超过 20 个工作日
- **异地远程**：因个人原因需长期在异地办公的，需签署《异地办公补充协议》，明确工作时间、汇报节奏与保密义务

## 工时与考勤

远程办公期间工时要求与办公室一致：
- 核心工作时间 10:00-16:00 必须在线
- 每日通过打卡系统提交 To-Do 与完成情况
- 参加日会/周会不迟到不缺席（视频镜头默认开启）

## 设备与网络

- 公司提供办公电脑与显示器，员工需妥善保管
- 家庭网络要求 100Mbps 及以上，公司报销 100 元/月网费
- 涉及内网访问必须走公司 VPN，禁止在公共 WiFi 处理敏感数据

## 数据安全要求

远程办公期间的数据安全红线：
1. 公司代码/文档禁止拷贝至个人设备
2. 屏幕不得对准公共视野，家人访客期间需锁屏
3. 与工作无关的软件（游戏、盗版工具）不得安装在办公电脑
4. 每日下班后关闭 VPN 与代码仓库权限

## 违规处理

- **首次违规**：书面警告 + 培训
- **二次违规**：取消远程办公资格 6 个月
- **严重违规**（数据泄露、伪造工时）**：**依据劳动合同解除条款处理，情节严重的追究法律责任

## 常见误区

**误区 1**：远程期间可以在其他公司兼职
→ 错。所有员工受禁止兼职条款约束，无论是否远程

**误区 2**：远程办公可以自由安排时间
→ 错。核心工作时间必须在线，与办公室员工同步

**误区 3**：远程期间发生工伤公司不负责
→ 错。经批准的远程办公期间发生工伤，公司仍承担相应责任
